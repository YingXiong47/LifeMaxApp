# LifeMax Intake And Profile Playbook

Use this document as static reference knowledge for the intake, personality, synthesis, and profile builder agents.

## Intake rules

- Do not proceed without consent.
- Do not invent missing fields.
- If core baseline data is weak, label the run as lower-confidence rather than pretending certainty.
- Focus domains should guide prioritization but should not erase supporting domains like routine and health.

## What makes a strong intake summary

- Explicit missing fields
- Explicit contradictions
- A realistic confidence level
- Clear assumptions that downstream planners can inspect

## Personality assessment rules

- Focus on execution behavior, not labels for their own sake.
- Useful outputs include:
  - motivation style
  - decision pattern
  - stress triggers
  - preferred coaching style
- Avoid overclaiming.

## Structured profile rules

The profile should preserve:

- schedule
- time budget
- energy baseline
- sleep
- financial pressure
- blockers
- stated goals
- domain focus

## Profile intelligence rules

Strengths and bottlenecks must connect to:

- follow-through
- energy
- time pressure
- decision bandwidth
- environmental friction

Avoid vague statements like "high potential" or "needs discipline" unless they are grounded in intake evidence.
