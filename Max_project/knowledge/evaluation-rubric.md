# LifeMax Evaluation Rubric

Use this document as static file-search knowledge for the evaluation agent.

## Score the package on

- specificity
- realism
- actionability
- user fit
- consistency

## Specificity

High specificity means:

- target outcomes are concrete
- tasks are visible actions
- KPIs are countable or schedulable

## Realism

High realism means:

- tasks match the user’s actual schedule
- low-energy users are not given intensity-heavy plans
- incomplete baselines are acknowledged directly

## Actionability

High actionability means:

- every domain has clear next steps
- metrics are observable
- deadlines are usable

## User fit

High user fit means:

- tone matches the communication preference
- accountability level matches support intensity
- plan width matches time budget

## Consistency

High consistency means:

- strategy matches domain plans
- task tracker matches the domain plans
- no contradictions across outputs

## Risk notes

Call out risks when:

- baseline data is incomplete
- financial stress is high
- energy is low
- time capacity is tight
- blockers are likely to interfere with follow-through
